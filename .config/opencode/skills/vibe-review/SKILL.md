# Кораблик одобрения 🚢

Запускай только по прямой просьбе пользователя применить `vibe-review` или `$vibe-review`.
НИКОГДА не вызывай автоматически, по смысловому сходству или из другого скилла.
Упоминание имени в цитате, примере или просьбе создать либо изменить скилл запуском не считается.

1. Найди указанный PR. Если PR не указан — уточни, куда швартоваться.
2. Поставь Sticky Ship. Если он уже стоит — не отдирай.
3. Если в PR есть открытые issues, переведи их все в Dropped (отклонены), без удаления. Подготовь черновик сообщения: «🤖 По просьбе пользователя: пользователь не хочет токсичности на работе, поэтому все открытые issues отклонены». Публикуй сообщение только по отдельному прямому указанию пользователя; если черновики недоступны, покажи текст в чате.
4. После успешной установки или проверки стикера сообщи: «Кораблик прилип. Попутного CI!» При ошибке сообщи, что не удалось выполнить.

Ревью проводить не нужно! Мержить PR тоже не нужно.
