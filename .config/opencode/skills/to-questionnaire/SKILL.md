---
name: to-questionnaire
description: Turn a decision the user cannot answer alone into a questionnaire for the person who holds the missing knowledge.
disable-model-invocation: true
---

Before writing, read `../_shared/artifact-policy.md` and follow it.

Interview the user only about the send:

1. Identify the recipient's role, expertise, relationship to the user, and existing context.
2. Identify the concrete facts or decisions the user needs back.
3. Write a questionnaire ordered by importance, grouping questions by theme when useful.

The document must contain a title, purpose, sender and recipient, how answers will be used, concise context, answering guidance, one idea per question with an answer area, and a closing catch-all question. Add “why this matters” only where a question could otherwise be misunderstood.

Finish only when every requested fact or decision is covered and report the artifact path.
