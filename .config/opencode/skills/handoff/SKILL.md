---
name: handoff
description: Create a compact handoff document so a fresh agent can continue the current work.
argument-hint: "What will the next session be used for?"
disable-model-invocation: true
---

Before writing, read `../_shared/artifact-policy.md` and follow it.

Write a handoff for an agent with no access to the current conversation. Include the live objective, current state, settled decisions, rejected alternatives that remain load-bearing, open work in dependency order, verification already performed, unverified assumptions, hazards, and suggested skills.

Reference existing specs, plans, issues, or other durable artifacts by path or URL instead of copying them. Redact sensitive information. If the user supplies an argument, tailor the handoff to that next-session focus.
